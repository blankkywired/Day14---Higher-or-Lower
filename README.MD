# Higher or Lower

**Higher or Lower** is a straightforward Python game in which the user guesses which celebrity has a higher number of Instagram followers.

## How It Works

* The algorithm randomly selects two celebrity profiles.
* The user is shown each person's name, a brief description, and their country of origin.
* The user must choose which profile has the larger follower count.
* A correct answer awards one point and generates a new comparison.
* An incorrect answer ends the game and displays the final score.

## Purpose

This project was developed to demonstrate essential Python concepts, including:

* Working with dictionaries and lists
* Random data selection
* Loops and user input handling
